J A R V I S

private personal assistant · single user

JARVIS is a private, self-hosted personal assistant running on its owner's own server. It is not a product and it is not offered to the public. It has exactly one user: its owner.

What it does

  • Reads the owner's own Google Calendar to build a daily briefing and a plan for the day.
  • Creates and updates events on two calendars the owner has set aside for it — a personal planning calendar and a school timetable calendar.
  • Reports those events to the owner by message and by phone call.

Why this page exists

Google requires any application that asks for access to Google account data to publish a home page and a privacy policy. This is that page.
