PRIVACY POLICY

JARVIS · private personal assistant · last updated 30 October 2026

JARVIS is a private, self-hosted personal assistant with a single user: its owner, the person who created this Google Cloud project and granted it access to their own Google Account. It is not offered to, installed by, or usable by anyone else.

What it accesses

With the owner's explicit consent, the application requests one Google permission: https://www.googleapis.com/auth/calendar — read and write access to the owner's own Google Calendar. No other Google service is requested. There is no access to Gmail, Drive, Contacts, Photos or any other Google data.

How the data is used

Calendar data is used for one purpose only: to tell the owner what is on their own calendar, and to create or update events on calendars the owner has set aside for that purpose. Nothing else is derived from it.

Where the data is stored

Calendar data is processed on the owner's own server. It is not stored on any third-party service and it is not used to train any machine-learning model. The authorisation token issued by Google is kept on that server, readable only by the owner, and is used solely to make the API calls described above.

Sharing

Calendar data is never sold, rented, published, or shared with any third party. No advertising is involved. No analytics or tracking is used. The only recipient of the information is the owner themselves, by message or by automated phone call to their own number.

Retention and deletion

Nothing is retained beyond what the owner's own Google Calendar already holds. The owner can revoke the application's access at any time at myaccount.google.com/permissions, which ends all access immediately; the stored token then becomes unusable. The owner may also delete the Google Cloud project itself, which removes the application entirely.

Limited Use

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
